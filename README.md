LATOKEN is a centralized cryptocurrency exchange (latoken.com) offering spot trading, a P2P marketplace and token listings. It publishes a public REST API v2 (market data, accounts, orders, stop and bulk orders, transfers, transactions and withdrawals signed with HMAC headers), a P2P API v1 and a STOMP WebSocket API, each documented with Redoc from a Swagger 2.0 contract at api.latoken.com/doc/, plus first-party Python, C# and Java clients.

**Areas:** Company · Cryptocurrency · Exchange · Trading · Market Data · P2P · WebSocket
